# Do it

macOS용 상시 노출 할 일·일정 위젯의 첫 실행 가능한 MVP입니다.

## 실행

```bash
npm install
npm run dev
```

## macOS 다운로드용 앱 만들기

```bash
npm run package:mac
```

생성 결과는 `release/Do it-0.1.0.dmg`와 `release/mac/Do it.app`입니다. 현재 빌드는 Apple 개발자 서명·공증 전의 로컬 테스트용 unsigned 앱입니다.

## 현재 범위

- 접힘 기본, hover 시 남은 할 일 개수, 클릭 시 전체 목록
- 개중요 / 보통 / 천처니 뱃지형 중요도
- 체크박스 완료 및 오늘 할 일 추가. 오늘 회의록 페이지를 저장 위치로 선택하면 Notion 체크박스도 생성
- 할 일 목록의 연필 버튼으로 내용 수정. 로컬 할 일은 제목·설명을, Notion 할 일은 원본 체크박스 문구를 수정
- 회의 시작 30분 전 위젯 안내 계산
- 기기 상단 중앙 기본 배치, 드래그 이동 및 위치 저장
- 할 일별 macOS 푸시 리마인드
- 항상 위, 자동 실행, 내용 숨김 설정
- 로컬 영구 저장
- 지정된 Notion 회의록 DB의 일정과 오늘 페이지의 체크박스 양방향 동기화
- 상위 제목이나 들여쓴 부모 항목을 설명으로, 회의록 페이지 이름을 작은 출처 텍스트로 표시하고 Notion 바로가기 제공
- 오늘 일정을 할 일 위의 가로 스크롤 카드로 표시
- 회의록에 적은 `2시 플랫폼사업팀 주간회의`, `14:00~15:00 주간회의` 같은 문장을 오늘 타임라인으로 변환
- Microsoft 계정 캘린더 읽기 및 5분 간격 갱신(조직에서 앱 등록을 허용한 경우)

설정에서 Notion 액세스 토큰을 연결하면 **회의록 DB**의 `Name`·`날짜` 속성을 읽고, 오늘 날짜 페이지 안의 체크박스를 할 일로 읽습니다. 앱에서 완료 여부를 변경하면 해당 체크박스에 반영됩니다. 제목 아래 체크박스는 가까운 제목을, 체크박스 안에 들여쓴 하위 체크박스는 부모 항목을 설명으로 표시합니다. 출처 페이지명은 설명 아래에 더 작은 글씨로 표시합니다.

Notion에서 가져온 할 일의 설명은 상위 제목·부모 항목에서 자동으로 정해집니다. 앱의 수정 화면에서는 체크박스 문구를 바꿀 수 있고, 설명을 바꾸려면 Notion 원본에서 상위 항목을 수정해야 합니다. 문구 수정 시 다른 인라인 서식과 `P1`·`P2`·`P3` 코드는 가능한 범위에서 유지합니다.

각 체크박스 본문 옆에 Notion **인라인 코드**로 `P1`, `P2`, `P3`을 적으면 앱에서 각각 개중요·보통·천처니 뱃지로 표시하고 제목에서는 코드 표기를 숨깁니다. 앱에서 중요도를 변경하면 해당 인라인 코드도 갱신합니다. 코드가 없는 기존 체크박스는 블록 색상을 기존 중요도로 사용하고, 색도 없으면 보통으로 표시합니다. 데이터베이스에 페이지 공통 `중요도` 속성을 추가할 필요는 없습니다.

오늘 회의록 페이지 안의 체크박스·문단·목록 항목에 `2시 플랫폼사업팀 주간회의`처럼 시간을 앞에 적으면 일정으로 인식합니다. 종료 시간을 적지 않으면 1시간 일정으로 표시하고, 시작 30분 전부터 위젯에 회의 안내를 보여줍니다. 예: `오후 2시 플랫폼사업팀 주간회의`, `14:00~15:00 플랫폼사업팀 주간회의`. 항목에 `회의`, `미팅`, `면담`, `콜`, `워크숍` 중 하나가 있어야 회의로 인식합니다. 오늘 날짜로 연결된 회의록 페이지의 내용만 읽으며, 변경 사항은 앱의 **지금 동기화** 또는 5분 간격 자동 동기화로 반영됩니다.

Teams와 같은 계정의 Microsoft 일정은 조직에서 Microsoft Entra 앱 등록을 허용한 경우에만 연결할 수 있습니다. 앱 등록에는 `Calendars.Read` 위임 권한과 공개 클라이언트 흐름이 필요합니다. 조직 권한이 없다면 위의 Notion 회의록 시간 문장으로 일정을 관리할 수 있습니다. 앱은 로컬 Teams 세션이나 브라우저 내부 데이터를 읽지 않습니다.

연동 인증 정보는 Electron의 macOS 보안 저장소로 암호화해 사용자 데이터 디렉터리에 저장합니다.
